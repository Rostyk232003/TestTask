## Стан: [Активна]

## Версія: v1.1

## Дата: 2026-09-10

## Контекст

Починаємо реалізацію базового каркасу .NET 8 рішення у відповідності до Clean Architecture, CQRS і Repository Pattern. На цьому етапі мета — створити стабільну структуру проекту, доменні сутності, базовий доступ до даних і базову розгортальну конфігурацію Web API без надмірної абстракції.

## Обраний патерн для поточного етапу

- Clean Architecture
- Repository Pattern
- CQRS для майбутніх команд/запитів
- SQLite через EF Core

Причина:

- на старті важливо забезпечити правильне розділення шарів;
- репозиторій дає стабільну точку входу для доступу до даних;
- CQRS ми застосовуємо там, де логіка стане складнішою, а не “на всі решти”.

## Опис реалізації

1. Створено .NET 8 solution з проектами: Domain, Application, Infrastructure, API.
2. Додано доменні сутності: `Hall`, `Service`, `HallService`, `Booking`.
3. Додано інтерфейс репозиторію для залів і базові DTO.
4. Налаштовано `AppDbContext` для SQLite з сідінгом початкових даних.
5. Підключено API до EF Core, Swagger і базовий endpoint для перегляду залів.

- проект збирається без помилок;
- є чітка структура по шарах;
- можна запустити Web API;
- використовуються явні типи та стандартизоване документування.
