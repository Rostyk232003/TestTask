# Історія промптів: ручна перевірка розрахунку цін

## Стан: [Активна]
## Версія: v1.2.1
## Дата: 2026-09-11

## Зміна
Для ручної перевірки додано:
- синхронізацію seed-даних для існуючої SQLite-бази;
- нормативні ціни залів A/B/C;
- нормативні ціни Projector, Wi-Fi та Sound;
- `GET /api/services` для перегляду послуг через API.

## Очікувані дані
- Hall A: 50 місць, 2000 грн/год.
- Hall B: 100 місць, 3500 грн/год.
- Hall C: 30 місць, 1500 грн/год.
- Projector: 500 грн.
- Wi-Fi: 300 грн.
- Sound: 700 грн.

## Перевірка
1. Запустити API.
2. Викликати `GET /api/halls` і `GET /api/services`.
3. Викликати `POST /api/pricing/calculate` для ранкового, стандартного, пікового та вечірнього часу.
4. Перевірити суму `HallPrice`, `ServicesCost` і `TotalPrice`.
